# Illustration prompts — Bloqvia homepage

One image per `Illustration` slot. Generate at the slot's aspect ratio, export PNG (or WebP) at 2× the display size, drop into `public/illustrations/` and pass the path as `src`. Works in Midjourney, Ideogram, Canva's image generator, DALL·E, Flux; adjust syntax per tool.

## Shared style block (paste at the end of every prompt)

> Style: premium editorial 3D render, sculptural geometric forms with soft rounded edges, matte and satin materials, atmospheric studio lighting with one warm key light and lavender fill, subtle depth of field, rich but restrained colour. Palette strictly: midnight navy #16243A background, electric lime #C7F36B as the single bright accent, lavender #B9B2EF and soft coral #F5A58B as secondary tones, warm ivory #F7F4EB highlights. Mature, calm, intelligent; no text, no logos, no people's faces, no cartoon characters, no neon glow, no hexagon grids, no coins with dollar signs, no generic "crypto" clichés.

Negative prompt (tools that take one): text, watermark, logo, hexagons, neon, glowing grid, cartoon, chibi, clip art, plastic toy, dollar sign, bitcoin symbol, blurry, busy background.

## 1. Hero — 16:10 (desktop) and 4:3 (mobile crop)

Deep navy space around it with soft atmospheric haze; the composition reads left-to-right with a sense of forward motion. Leave the left third calmer for a headline overlay. [style block]

## 2. Introducing Web3 — 1:1

Soft shadow on a satin navy floor. [style block]
